_archi_ ("AI Augmented Research Chat Intelligence") is a retrieval-augmented
generation framework for research and education teams that need a
low-barrier-to-entry, configurable, private, and extensible assistant. It
combines data retrieval (web links, repositories, local files, JIRA) with LLMs,
offers chat and email-bot interfaces, and supports both local and API-based
models. First developed at MIT for the SubMIT computing project; now used for
chat, ticketing, and course-support workflows across academic and research
organizations.

Useful when: you want to stand up a RAG assistant over your own facility's
documentation, tickets, or course material, and want to run it privately.

Not useful when: you need an agent that _acts_ on HEP infrastructure (submits
jobs, queries datasets) rather than answering questions about it — pair it with
an MCP server from this list for that.
