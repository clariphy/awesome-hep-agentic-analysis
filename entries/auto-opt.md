The SKILL.md is a template for an agentic skill to perform automatic (Python)
code optimization in an iterative loop. This is useful for when you have working
analysis code, but want to optimize it for performance (e.g. runtime or low RAM
usage) before submitting it to a cluster as batch jobs.
