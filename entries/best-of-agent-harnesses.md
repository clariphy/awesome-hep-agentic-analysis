A "best-of" style curated and ranked list of AI agent harnesses (Claude Code,
Codex, Cursor, and 100+ others), rescored on a weekly cadence. It has no HEP
angle — it doesn't know about physics workflows — but it's a useful reference
when picking or comparing the underlying harness that a HEP-specific tool in
this list (an MCP server, a skill, a marketplace) is meant to run inside.

Useful when: you're choosing which agent harness to standardize on, or want to
see how a harness you already use compares against alternatives.

Not useful when: you're looking for HEP-specific tooling itself — this list
ranks generic harnesses, it doesn't index HEP analysis tools.
